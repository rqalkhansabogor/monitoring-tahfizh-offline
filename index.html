2. Tentukan tujuan file
Jangan bingung: jika file diseret ke kotak GANTI DATA, sistem menyiapkan proses Ganti. Jika diseret ke GABUNGKAN DATA, sistem menyiapkan proses Gabungkan. Data belum berubah sampai Anda melihat hasil pemeriksaan dan menekan tombol konfirmasi.
