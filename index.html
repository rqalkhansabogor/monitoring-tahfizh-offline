5 Bersiap Memasukkan Nama Santri, Kelas, Bacaan & Hafalan
Nama tidak harus lengkap. Anda boleh menyebut nama panggilan, nama depan, atau potongan nama. ChatGPT harus mencocokkannya dengan nama santri di kelas yang Anda sebutkan.

Urutan yang dianjurkan: Nama santri → Kelas → Bacaan/Hafalan/Murojaah/Catatan.

Jika hanya ada satu kandidat yang cocok, gunakan nama lengkap yang tersimpan. Jika ada beberapa kandidat atau tidak ditemukan, jangan menebak; tanyakan kepada Anda. Kelas menjadi pembatas utama pencarian nama.
Contoh: “Kelas Abdurrahman. Ahmad, hafalan An-Naba ayat 1–10. Aisyah, bacaan An-Nazi’at ayat 1–15. Rafa, murojaah Al-Mursalat ayat 1–20.” 
Saya akan membacakan data dengan urutan nama santri, kelas, kemudian bacaan, hafalan, murojaah, atau catatan.

Nama yang saya sebutkan tidak harus nama lengkap. Jika saya hanya menyebut nama panggilan, nama depan, atau potongan nama, cocokkan dengan daftar santri yang terdapat pada data lama dan gunakan kelas yang saya sebutkan sebagai pembatas pencarian.

Aturan pencocokan:
1. Cari nama yang cocok di kelas yang saya sebutkan.
2. Nama boleh berupa nama lengkap, panggilan, nama depan, atau potongan nama.
3. Jika hanya ada satu kandidat yang cocok, gunakan nama lengkap yang tersimpan di data.
4. Jika ada beberapa kandidat yang mungkin cocok, jangan menebak. Tanyakan kepada saya.
5. Jika nama tidak ditemukan di kelas tersebut, beri tahu saya dan jangan membuat santri baru secara otomatis.
6. Jangan memindahkan santri ke kelas lain hanya karena nama terlihat mirip.
7. Pertahankan seluruh data lama dan tambahkan data baru sesuai instruksi saya.
8. Jangan menghapus atau menimpa riwayat lama secara sembarangan.

Saya akan melanjutkan memberikan nama, kelas, lalu data hafalan/bacaan/murojaah.

Data baru sudah selesai saya berikan.

Sekarang gabungkan data baru tersebut dengan data lama dari CSV yang sebelumnya saya berikan.

Aturan wajib:
- Pertahankan seluruh data lama.
- Tambahkan data baru.
- Jangan menghapus data lama.
- Jangan mengganti data lama secara sembarangan.
- Jangan menghilangkan riwayat, bacaan, hafalan, murojaah, catatan, tracking, presensi, tugas, target, atau data lain.
- Pertahankan struktur CSV asli persis seperti file sumber.
- Pertahankan semua kolom, Type, Key, Value, dan data yang tidak sedang diubah.
- Pastikan data santri tetap lengkap dan tidak ada santri yang hilang.
- Pastikan data baru masuk ke struktur yang benar.

IDENTITAS / VERSI FILE WAJIB DIPERTAHANKAN:
- Baca metadata versi yang ada di CSV, jika tersedia.
- Catat dan pertahankan informasi: nomor/file ke berapa, File ID, siapa yang membuat/mengupload file, perangkat (HP atau Laptop/PC), nama perangkat jika ada, hari, tanggal, dan jam/waktu WIB.
- Bedakan dengan jelas antara identitas file sumber dan waktu/operator saat proses penggabungan dilakukan.
- Jangan menghapus atau mengganti metadata identitas file sumber hanya karena CSV sedang digabungkan.
- Jika CSV memiliki metadata versi, jangan membuat identitas baru secara asal dan jangan menghilangkan identitas sumber.
- Jika ada informasi identitas yang tidak tersedia di CSV, jangan menebak; beri tahu saya bahwa informasi tersebut tidak tersedia.

SEBELUM MEMBUAT FILE HASIL:
- Tampilkan ringkasan singkat bahwa file sumber telah dikenali.
- Sebutkan File ID / nomor file, siapa yang membuat atau mengupload, perangkat, hari, tanggal, dan jam jika data tersebut tersedia.
- Beri tahu jika ada metadata yang tidak tersedia.
- Pastikan jumlah dan isi data lama tetap aman sebelum hasil dibuat.

Setelah selesai, buatkan file CSV hasil gabungan yang siap dimasukkan kembali ke web menggunakan menu:
Data → Import Data → Gabungkan.

File hasil harus tetap kompatibel dengan format CSV web RQ Al-Khansa. Jangan mengubah format CSV yang dibutuhkan oleh web.

PENTING: jangan memilih atau menyarankan mode Ganti. Hasil ini ditujukan untuk mode Gabungkan agar data lama tetap dipertahankan.
Saat memasukkan hasil kembali ke web, gunakan Gabungkan agar data lama tetap dipertahankan. Jangan pilih Ganti kecuali memang ingin mengganti seluruh data.
